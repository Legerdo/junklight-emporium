# 별고물 상회 — 진행 기록

## 설계 핵심
- 대표 상호작용: **재질 연쇄 작업대**. 수레가 고물을 쏟으면, 한정된 타격(수레당 3~7번)으로 어디를 칠지 고른다. 재질마다 부서질 때 반응이 달라(나무=파편·불, 유리=유리 파편, 금속=스파크, 천=약화 먼지, 태엽=폭발, 별=파동) 한 번의 선택이 연쇄로 번진다.
- 연타 방지: 타격 수가 수레당 고정, 타격마다 짧은 예비 동작. 연쇄 유지 시간 안에 다음 타격을 넣으면 연쇄 배율이 이어진다(타이밍 기술).
- 화폐 2종: 동전(강화·도구·장치·골동품), 별빛(등불 → 새 지역 → 별의 심장).
- 골동품 = 진열장 장착 규칙 변경(예: 프리즘=파편이 금속에 맞으면 스파크). 드롭·의뢰·떠돌이 상인 세 경로로 모두 얻을 수 있다.
- 장치 = 레일 소켓(열 위치가 곧 작업 줄). 자동화 역할 변화: 까치 조수(자동 수레), 까치의 눈(쉬면 남은 타격을 대신 씀).
- 클라이맥스: 별의 심장(세 겹, 겹마다 약한 반응이 다름). 망치로는 거의 안 깎이고 주변 연쇄로만 깎인다 → 배운 반응을 모두 쓰게 한다.
- 엔딩 후: 전설 골동품, 추가 의뢰, 「다음 밤」(별자리 규칙 4종 + 맑은 밤, 골동품·도감·배지 유지).

## 바꾼 결정과 이유
- 작업대 폭 288→210px: 물건이 너무 흩어져 연쇄가 약하고 화면이 비어 보였다.
- 장치 발동 시점: "수레가 멈추면" → "그 수레의 첫 타격 때". 후반에 장치가 플레이어 입력 없이 수레를 다 치워 버려 선택이 사라졌기 때문.
- 싹쓸이 보너스(남은 타격 × 12%): 수레를 다 비울 수 있게 되면 도구 차이가 수익에 안 드러났다. 적은 타격으로 비우는 연쇄형 빌드에 보상.
- 자석: 금속만 건드려 두 번째 타격부터 헛손질 → 끝으로 누른 자리의 비금속도 누르고, 모은 금속 전체에 전기를 흘리게 변경.
- 심장 약점 배율 ×3/×1 → ×4/×0.7: 단계별로 빌드를 바꿀 이유를 키움.
- 불로 부순 물건 동전 +50%: 불 빌드는 느리지만 값어치가 있게.

## 검증 도구
- `npm run sim -- --seed=N [--build=mallet|magnet|...] [-v]`: 사람 속도(타격 간격 1.1초, 클릭·구매 지연)를 흉내 내는 봇의 **가속 시뮬레이션**. 실제 규칙 코드 사용.
- `npx tsx tools/toolbench.ts 40 [heart]`: 같은 조건에서 빌드별 분당 수익 / 심장 단계별 피해 비교.
- `npx tsx tools/shot.ts basic|late|heart`: Playwright로 실제 화면 조작·스크린샷. late/heart는 `?debug` 강제 해금(개발용) 상태.
- `npm test`: 규칙 불변식 단위 테스트.

## 검증 기록 (2026-09-29)
구분: [정상] 강제 해금 없는 정상 경제 · [가속] 봇이 사람 속도를 흉내 낸 시뮬레이션 또는 연출 12배속 · [강제] `?debug` 해금 상태.

- [정상·가속] 헤드리스 봇 완주: 시드 1 → 엔딩 53분(수레 411), 시드 2·3도 엔딩 도달. 지역별 체류 약 4 / 7 / 12 / 15 / 11분. 사람은 조준·판단이 더 느리므로 60~80분으로 추정(실제 사용자 테스트는 하지 않음).
- [정상·가속] 대체 빌드: 망치만 쓰는 빌드도 엔딩 도달. 별자리 「빈손자리」「유리잔자리」(골동품 인계 없이)도 엔딩 도달(각 53분, 51분).
- [가속] 빌드 비교(toolbench): 온실에서 소리굽쇠 빌드가 망치보다 동전 +30%. 심장 단계별로 유리 결정은 굽쇠(망치의 2.2배), 빛나는 핵은 자석·별망치(1.3배)가 가장 강함. 불 빌드는 가장 느리지만 불 동전 보너스로 보완.
- [정상·가속] 실제 production 빌드에서 브라우저 완주(e2e): 신규 저장 → 엔딩, 게임 시간 52분, 콘솔 오류 0. 두 번째 등불 직후 새로고침: 동전·별빛·수레·골동품·진행 중 작업대 모두 동일하게 복구.
- [정상] 브라우저 기본 조작(basic): 인트로 → 종 → 쏟기 → 클릭 타격(흰 번쩍임·팝업·동전 비행) → 정산.
- [정상] 처리 중 새로고침(reload): 타격 직후 저장·새로고침, 동전/남은 물건/남은 타격/파괴 수 동일.
- [강제] 후반 연쇄·심장·엔딩 연출·패널 7종·다음 밤 UI 화면 확인. 후반 성능: 1280 프레임 평균 16.66ms, p95 17.9ms, 최대 23.8ms.
- 단위 테스트 10개: 결정성, 연쇄 종료·물건 수 상한, 보상 1회, 중간 저장 복구, 심장 보존, 다음 밤, 골동품 획득 경로, 스프라이트 존재, 첫 구매 도달.
- 테스트가 찾은 버그: 타격 직후 곧바로 정산하면 타격이 처리되기 전에 수레가 끝날 수 있었다 → 타격 시 '조용함' 타이머 초기화로 수정.

## 남은 제한
- 소리는 합성 코드와 오류 없음만 확인했고, 실제로 들어 보며 음량·음색을 조율하지는 못했다.
- 재미·이해도는 자체 판단이며 실제 사용자 테스트는 하지 않았다.
- 화면 배율이 정수가 아닐 때(예: 1280×720) 픽셀 크기가 미세하게 고르지 않다.
